Message de rappel

Prestataires

Le premier de la liste est choisi par défaut. Coche « Interventions » pour ceux à qui on peut demander autre chose qu'un pare-brise ou un lavage (vérification, ampoule, AdBlue…).

Tarifs hors taxe

Le prix est figé sur chaque demande au moment où elle est enregistrée : changer un tarif ne modifie pas les demandes déjà faites. Laisse le cubage vide pour « toutes tailles ».

Accès à l'appli

Chaque personne se connecte avec sa propre adresse. Un prestataire ne voit que ses demandes ; l'équipe City-Drop voit tout ; « lecture » voit tout sans rien modifier. Crée d'abord son compte dans Firebase (Authentication), puis ajoute son adresse ici.

À faire une fois avant de publier les nouvelles règles :

Sites et adresses

L'adresse se remplit toute seule dans la demande quand on choisit le site.

Flotte

Modèles proposés dans la demande. Choisir un modèle remplit le cubage.

Liaison avec le Google Sheet

Un bouton « Cocher dans le Google Sheet » coche la colonne « OK confirmé » des plaques confirmées. À installer une seule fois :

  1. Dans ton Google Sheet pare-brise : Extensions › Apps Script.
  2. Remplace tout le code par le script ci-dessous, puis enregistre.
  3. Ajuste si besoin les 3 réglages en haut du script.
  4. Déployer › Nouveau déploiement, Application Web, exécuter en tant que Moi, accès city-drop.com.
  5. Colle ici l'URL qui finit par /exec.
